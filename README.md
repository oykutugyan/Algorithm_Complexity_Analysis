# Algorithm Complexity Analysis

## About the Code ('src/*.java')

This is a Java-based project designed to analyze and compare the performance, time complexities, and behaviors of various sorting algorithms (such as Comb Sort, Shaker Sort, Shell Sort, Radix Sort, Insertion Sort, etc.). It features **Object-Oriented Programming (OOP) principles**, **modular sorting implementations**, **dataset handling**, and **algorithmic performance evaluation**.
The system processes different datasets to measure execution efficiency, step counts, and computational overhead across various sorting strategies.

For detailed insights, empirical results, mathematical time complexity derivations, and complete performance analysis charts, please refer to the comprehensive report.pdf included in the root directory. It covers an in-depth breakdown of each sorting algorithm's behavior across random, sorted, and reversed datasets.

---

## Prerequisites & External Libraries

Java Development Kit (JDK): Version 8 or higher.

X-Chart Library: Required for generating performance comparison charts (xchart.jar). Ensure the X-Chart library is added to your project's build path/dependencies.
